# Data Dictionary

| Column | Type | Definition |
|---|---|---|
| OrderID | Text | Unique order ID |
| OrderDate | Date | Order date during 2025 |
| Customer | Text | Synthetic customer label |
| Product | Text | Product purchased |
| Category | Text | Product category |
| Region | Text | Sales region |
| City | Text | City in the sample region |
| Salesperson | Text | Synthetic salesperson name |
| Quantity | Integer | Units purchased |
| UnitPrice | Numeric | Unit price before discount |
| DiscountPct | Decimal | Discount fraction, e.g. 0.10 means 10% |
| Sales | Numeric | Revenue after discount |
| Cost | Numeric | Estimated cost for units sold |
| Profit | Numeric | Sales minus cost |

All rows are synthetic, generated for demonstration and learning. Values do not represent actual customers or businesses.
